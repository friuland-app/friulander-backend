# Friulander Design System

## Color Palette

### Primary Colors (Friuli Inspired)
- **Forest Green**: #2D5A27 - Primary buttons, headers
- **Tagliamento Blue**: #4A90E2 - Links, water elements
- **Hill Gold**: #D4A017 - Accents, rewards
- **Dolomite Grey**: #6B7280 - Secondary text
- **Friuli White**: #F9FAFB - Backgrounds

### Type Colors
- Primary: #111827
- Secondary: #6B7280
- Error: #EF4444
- Success: #10B981

## Typography

### Fonts
- **Primary**: Inter (Google Fonts)
- **Secondary**: Poppins (Google Fonts)

### Font Scale
- H1: 32px / 700
- H2: 24px / 600
- H3: 20px / 600
- Body: 14px / 400
- Small: 12px / 400

## Spacing
Based on 4px unit: xs(4), sm(8), md(16), lg(24), xl(32), 2xl(48)

## Components

### Buttons
- Height: 48px
- Border radius: 12px

### Cards
- Border radius: 16px
