# Battle Screen Specification

## Layout
- Enemy creature: Top right
- Player creature: Bottom left
- Health bars: Animated for both
- Move menu: 4 moves available
- Action log: Text log of actions
- Flee button: Bottom right
- Turn indicator: Top right

## UI Elements
- Back button (top left)
- Turn indicator (top right)
- Enemy health bar (red)
- Player health bar (green)
- Move buttons (2x2 grid)
- Action log (center)
- Flee button (red)

## Animations
- Attack: Lunge forward, impact, return
- Damage: Flash red, shake, knockback
- Healing: Green glow, particles
- Special move: Charge, burst, impact

## Particle Effects
- Attack: Gold particles
- Damage: Red particles
- Healing: Green particles
- Special: Purple spiral

## States
- Player turn: Moves enabled
- Enemy turn: Moves disabled
- Victory/Defeat/Fled overlays
