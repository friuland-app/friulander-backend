# Android Resources

## Icone

Le icone Android devono essere posizionate in:
- `mipmap-mdpi/ic_launcher.png` - 48x48
- `mipmap-hdpi/ic_launcher.png` - 72x72
- `mipmap-xhdpi/ic_launcher.png` - 96x96
- `mipmap-xxhdpi/ic_launcher.png` - 144x144
- `mipmap-xxxhdpi/ic_launcher.png` - 192x192

## Splash Screen

Creare splash screen in:
- `drawable/splash.png` - 1920x1080

## Istruzioni

1. Usa l'icona SVG esistente `icon.svg` come base
2. Esporta in PNG alle dimensioni richieste
3. Usa Android Studio o ImageMagick per generare le varianti
4. Splash screen deve includere logo e nome app
