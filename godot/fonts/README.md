# Font per Friulander

## Font Richiesti

Questo gioco utilizza i seguenti font:

### 1. Inter (Regular + Bold)
Font sans-serif moderno e leggibile per il testo dell'interfaccia.

**Download:** https://fonts.google.com/specimen/Inter

**File da copiare qui:**
- `Inter-Regular.ttf`
- `Inter-Bold.ttf`

### 2. Poppins (Regular + Bold)
Font con carattere geometrico per titoli ed elementi di enfasi.

**Download:** https://fonts.google.com/specimen/Poppins

**File da copiare qui:**
- `Poppins-Regular.ttf`
- `Poppins-Bold.ttf`

## Istruzioni

1. Clicca i link sopra
2. Premi il pulsante "Download"
3. Estrai i file ZIP
4. Trova i file `.ttf` elencati sopra
5. Copiali in questa cartella (`godot/fonts/`)
6. Riavvia Godot

## Verifica

All'avvio del gioco, controlla la console Output in Godot:
- ✅ "Tutti i font sono presenti" = Font caricati correttamente
- ⚠️ "Font mancanti" = Devi scaricare i font elencati sopra

## Note

- I font sono opzionali ma consigliati per l'esperienza completa
- Senza questi font, Godot utilizzerà i font di sistema di default
- I font Google sono gratuiti e open-source
